## ダウンロードして遊ぶまで

1. 上の「Windows版をダウンロード」をクリックします。
2. ダウンロードしたZIPを右クリックし、<strong>「すべて展開」→「展開」</strong>を選びます。
3. 展開したフォルダーを開き、**`MinnaRPG.exe`** をダブルクリックします。同名のフォルダーがもう1つ入っている場合は、その中を開いてください。末尾が非表示の設定では「MinnaRPG」と表示されるので、種類が「アプリケーション」のものを選びます。
4. タイトル画面で<strong>「ゲーム開始」→「はじめから」</strong>を選びます。保存した続きで遊ぶときは<strong>「つづきから」</strong>を選んでください。

**「はじめから」を選ぶと、現在の進行データが初期化されます。**

ゲームに必要なファイルが一緒に入っているので、展開したフォルダーは中身ごと保管してください。

## 最初の出撃

1. ゲーム内メニューの<strong>「装備」</strong>を開きます。
2. **武器・頭・胴・足**の4枠を確認し、空いている枠があれば、その枠と装備品を選んで<strong>「装備を確定」</strong>を押します。
3. <strong>「戻る」→「ステージ選択」</strong>へ進み、ステージを選んで<strong>「このステージに出撃」</strong>を押します。

4枠のうち1つでも空いていると出撃できません。

## 音量と画面表示

タイトル画面、またはゲーム内メニューの<strong>「オプション」</strong>で変更できます。

- マスター・BGM・SEの音量
- ウィンドウ・ボーダーレス全画面・全画面の表示モード

## 終了と再開

ウィンドウ右上の「×」で終了します。全画面表示の場合は**Alt + F4**を押してください。次回は `MinnaRPG.exe` を開き、<strong>「ゲーム開始」→「つづきから」</strong>で再開できます。

## うまくいかないとき

| 状態 | 確認すること |
|---|---|
| 実行ファイルが見つからない | 展開したフォルダーの中にある同名のフォルダーも開いてください。末尾が非表示の場合は「MinnaRPG」「アプリケーション」を探します。 |
| 起動時に必要なファイルが見つからない | ZIPをもう一度「すべて展開」し、展開先の実行ファイルを起動してください。 |
| 出撃できない | 武器・頭・胴・足の4枠に装備が入っているか確認してください。 |
| 音が出ない | ゲーム内「オプション」のマスター・BGM・SEの音量を確認してください。 |
